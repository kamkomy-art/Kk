# تحليل (tehlil)

تطبيق تحليل فني للعملات الرقمية بمساعدة الذكاء الاصطناعي. يجيب بيانات سوق حيّة من Binance
(بدون مفتاح)، يحسب عليها مؤشرات فنية حقيقية بكود رياضي (RSI، MACD، متوسطات متحركة، بولينجر
باند)، ثم يطلب من Claude تفسيرها بالعربية. **القرار النهائي بالشراء أو البيع يعود للمستخدم دائمًا**
— التطبيق لا يصدر توصيات مباشرة ولا ينفّذ أي صفقات.

## البنية

```
tehlil/
├── server.js              # Express :8787 — نقاط API
├── lib/
│   ├── binance.js         # جلب الشموع والأسعار والبحث عن الرموز من Binance (عام، بلا مفتاح)
│   └── indicators.js      # حساب RSI / EMA / SMA / MACD / Bollinger Bands
├── vite.config.js         # Vite :5173 مع proxy لـ /api → :8787
├── index.html             # صفحة عربية RTL
└── src/
    ├── App.jsx            # التخطيط العام (قائمة متابعة + بحث + تحليل + دردشة)
    ├── main.jsx
    ├── api/client.js       # دوال fetch لنقاط /api/*
    └── components/
        ├── Watchlist.jsx       # قائمة متابعة ثابتة تتحدّث كل 30 ثانية
        ├── SearchBar.jsx        # بحث حر عن أي عملة USDT على Binance
        ├── AnalysisPanel.jsx    # مؤشرات العملة المختارة + تفسير Claude النصي
        └── Chat.jsx              # دردشة حرة streaming مع Claude
```

## نقاط API

| المسار | الوصف | يحتاج مفتاح Anthropic؟ |
| --- | --- | --- |
| `GET /api/watchlist` | سعر + مؤشر سريع (RSI + اتجاه) لكل عملة في القائمة الثابتة | لا |
| `GET /api/search?q=` | بحث عن رمز عملة USDT على Binance | لا |
| `POST /api/analyze` | مؤشرات كاملة لعملة محددة + تفسير نصي من Claude | نعم |
| `POST /api/messages` | proxy عام لدردشة حرة مع Claude (streaming) | نعم |

بيانات السوق (`watchlist`, `search`) عامة ومجانية من Binance ولا تحتاج مفتاح API إطلاقًا؛
مفتاح Anthropic لازم فقط لتوليد التفسير النصي والدردشة.

## التشغيل

1. أنشئ ملف `.env` وضع فيه مفتاحك الحقيقي:

   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

2. ثبّت الاعتماديات:

   ```bash
   npm install
   ```

3. شغّل الخادم وواجهة React معًا:

   ```bash
   npm run dev
   ```

   ثم افتح المتصفح على `http://localhost:5173`.

> ملاحظة: إن كنت تشغّل المشروع خلف جدار حماية أو بيئة شبكة مقيّدة، تأكد من السماح بالوصول
> إلى `api.binance.com` (المصدر العام لبيانات السوق) و `api.anthropic.com`.

## تخصيص قائمة المتابعة

قائمة المتابعة الافتراضية معرّفة في `server.js` (`WATCHLIST`) — عدّلها لأي أزواج USDT أخرى:

```js
const WATCHLIST = ["BTCUSDT", "ETHUSDT", "BNBUSDT", "SOLUSDT", "XRPUSDT"];
```

## البناء للإنتاج

```bash
npm run build
```

يُنتج ملفات الواجهة في `dist/`. لتشغيلها في الإنتاج تحتاج لتشغيل `server.js` بجانب خادم يقدّم
الملفات الساكنة (أو دمجه مع `express.static`).

## إخلاء مسؤولية

هذا التطبيق أداة تحليل ومعلومات فقط، وليس نصيحة استثمارية أو مالية. جميع البيانات والمؤشرات
والتفسيرات المعروضة لأغراض تعليمية/بحثية، والقرار النهائي بأي عملية شراء أو بيع مسؤولية
المستخدم وحده.
